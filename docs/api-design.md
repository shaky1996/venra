# API Design

No API endpoints have been implemented yet. Venra's backend is planned as a Spring Boot HTTP API serving the web application.

## Planned API modules

These modules are placeholders and will be designed only as their product workflows are implemented:

- Companies
- Users and memberships
- Drivers
- Trucks
- Trailers
- Documents
- Expirations
- Inspections
- Tickets and violations
- Claims
- Insurance recovery
- IFTA
- Company compliance
- FMCSA data
- Readiness overview
- Future assistant and search capabilities

## Initial conventions to decide later

- Base path and API versioning
- Request and response shapes
- Validation error format
- Pagination, filtering, and sorting
- Authentication and authorization behavior
- OpenAPI documentation

The first API design should stay limited to the first end-to-end feature rather than defining every module in advance.
